Criar tabela aula 4

CREATE TABLE Vendas (
    VendaID       INT AUTO_INCREMENT PRIMARY KEY,
    ClienteID     INT           NOT NULL,
    FuncionarioID INT           NULL,
    DataVenda     DATE          NOT NULL,
    TotalVenda    DECIMAL(10,2) NOT NULL DEFAULT 0,
    CONSTRAINT fk_vendas_cliente
        FOREIGN KEY (ClienteID)
        REFERENCES Clientes(ClienteID)
);

       ('Vela de ignição', 24.50, 800);

SET Preco = 42.50, Estoque = Estoque + 30
WHERE ProdutoID = 3;

DELETE FROM Produtos
WHERE ProdutoID = 8;
UPDATE e DELETE sem WHERE atingem todas as linhas. Rode antes um SELECT com o mesmo WHERE.

JOIN aula 6

-- só linhas com par dos dois lados
SELECT V.VendaID, C.Nome AS Cliente, P.Nome AS Produto
FROM Vendas V
JOIN Clientes   C ON V.ClienteID = C.ClienteID
JOIN ItensVenda I ON I.VendaID   = V.VendaID
JOIN Produtos   P ON I.ProdutoID = P.ProdutoID;

-- todas as linhas da esquerda
SELECT V.VendaID, F.Nome
FROM Vendas V
LEFT JOIN Funcionarios F
       ON V.FuncionarioID = F.FuncionarioID;

-- quem NÃO tem par
SELECT C.Nome
FROM Clientes C
LEFT JOIN Vendas V ON V.ClienteID = C.ClienteID
WHERE V.VendaID IS NULL;

Regra do ON: FK = PK. Linhas demais no resultado? ON faltando ou errado.

CASE e subconsulta aula 6

SELECT VendaID, TotalVenda,
       CASE WHEN TotalVenda < 1000 THEN 'Pequena'
            WHEN TotalVenda <= 5000 THEN 'Média'
            ELSE 'Grande' END AS Categoria
FROM Vendas;

SELECT Nome FROM Clientes
WHERE ClienteID IN (SELECT ClienteID FROM Vendas
                    WHERE TotalVenda > 5000);

Particularidades do MariaDB no XAMPP

SituaçãoO que aconteceO que fazer
FK escrita na linha da coluna: ClienteID INT REFERENCES Clientes(ClienteID)Na versão 10.4 o comando roda, mas nenhuma FK é criada.Escrever FOREIGN KEY (…) REFERENCES … em linha separada.
Concatenar com ||Por padrão, || é o operador lógico OR.Usar CONCAT().
FULL OUTER JOINNão existe: erro de sintaxe.Usar LEFT JOIN ou RIGHT JOIN.
Comparar com = NULLO resultado é NULL; nenhuma linha passa.Usar IS NULL.
Decimal com vírgula: 550,25A vírgula separa valores.Usar ponto: 550.25.
Nomes de tabela no WindowsAparecem em minúsculas (itensvenda).Normal; os comandos funcionam com qualquer caixa.
Aspas copiadas de PDF: ‘texto’Erro de sintaxe.Digitar aspas simples retas: 'texto'.
