Glossário

Os termos do curso, com a aula em que cada um aparece

Este glossário é a referência de vocabulário das aulas e das listas. Exemplos tirados da AutoNex.

Alias aulas 5 e 6
Apelido dado a uma coluna (Preco * Estoque AS ValorEmEstoque) ou a uma tabela (FROM Vendas V) dentro de uma consulta.
Atômico (valor) aula 1
Valor indivisível: um só por célula. Uma lista de telefones na mesma célula não é atômica.
Atributo aulas 1 e 2
Característica de uma entidade ou coluna de uma tabela. Preco é atributo de Produtos.
AUTO_INCREMENT aulas 3 e 4
Opção de coluna no MySQL/MariaDB: quando o valor não é informado, o SGBD usa o próximo número da sequência. Usada em chaves substitutas.
Banco de dados aula 1
Conjunto de dados estruturados, organizados conforme uma estrutura predefinida, que permite inserir, ler, alterar e excluir.
Cardinalidade aula 2
Quantas ocorrências de uma entidade podem se associar a uma ocorrência da outra: um (1) ou muitos (N). Um cliente compra em N vendas; uma venda é para 1 cliente → 1:N.
Chave alternativa aula 3
Chave candidata que não foi escolhida como primária. Em SQL costuma receber UNIQUE. Ex.: CNPJ em Clientes.
Chave candidata aula 3
Superchave mínima: identifica cada linha e não tem coluna sobrando.
Chave composta aulas 3 e 4
Chave formada por mais de uma coluna. Ex.: (LivroID, AutorID) em LivrosAutores.
Chave estrangeira — FK aulas 3 e 4
Coluna que guarda o valor da chave primária de outra tabela, criando o relacionamento. Vendas.ClienteID referencia Clientes.ClienteID.
Chave primária — PK aulas 1, 3 e 4
A chave candidata escolhida para identificar cada linha. Única, nunca NULL, uma por tabela.
Chave substituta (surrogate) aula 3
Coluna criada só para identificar a linha, sem significado no negócio. Ex.: ClienteID.
DCL aulas 4 e 7
Data Control Language. Comandos de controle de acesso: GRANT, REVOKE.
DDL aula 4
Data Definition Language. Comandos que definem a estrutura: CREATE, ALTER, DROP.
DER aula 2
Diagrama entidade-relacionamento. Desenho do modelo conceitual: retângulos (entidades), elipses (atributos), losangos (relacionamentos).
DML aula 5
Data Manipulation Language. Comandos que mexem nos dados: INSERT, UPDATE, DELETE.
Domínio aula 1
Conjunto de valores permitidos em uma coluna, definido pelo tipo de dado.
DQL aulas 5 e 6
Data Query Language. O comando de consulta: SELECT.
Entidade aula 2
Algo do minimundo sobre o qual se guardam dados: objeto, pessoa, evento. Vira tabela.
Entidade associativa aula 2
Entidade que nasce de um relacionamento N:N, guardando os atributos do par. Ex.: ItensVenda. Em SQL: tabela associativa.
Esquema aulas 1 e 3
Descrição da estrutura de uma relação: Produtos(ProdutoID, Nome, Descricao, Preco, Estoque).
Grau aula 1
Número de atributos de uma relação.
Identificador aula 2
Atributo (ou conjunto mínimo de atributos) que distingue cada ocorrência de uma entidade. Vira a chave primária.
Integridade referencial aulas 3 e 4
Garantia de que todo valor de uma FK existe na PK referenciada. Mantida pelo SGBD.
JOIN aula 6
Junção de tabelas numa consulta, casando linhas pela condição ON. INNER JOIN: só linhas com par dos dois lados. LEFT JOIN: todas da esquerda, com NULL onde faltar par.
Metadados aula 1
Dados sobre os dados: nomes das tabelas, colunas, tipos e restrições.
Minimundo aula 2
A parte do mundo real que o banco precisa representar; o texto de requisitos.
Modelo conceitual, lógico e físico aulas 2, 3 e 4
Conceitual: o DER. Lógico: tabelas, colunas e chaves. Físico: o script SQL para um SGBD específico.
NoSQL aula 7
Bancos não relacionais: chave-valor, documentos, colunas e grafos. Esquema flexível e escala horizontal.
NULL aulas 3 e 5
Ausência de valor. Não é zero nem texto vazio. Testa-se com IS NULL.
Procedure aula 7
Bloco de comandos SQL com nome e parâmetros, armazenado no banco e executado com CALL.
Produto cartesiano aula 6
Resultado de juntar tabelas sem condição: cada linha de uma combinada com todas da outra.
Relação aula 1
Nome formal da tabela no modelo relacional.
Relacionamento aula 2
Associação entre entidades. Tipos: 1:1, 1:N e N:N.
Restrição (constraint) aula 4
Regra que o SGBD aplica aos dados: PRIMARY KEY, FOREIGN KEY, NOT NULL, UNIQUE, DEFAULT.
SGBD aula 1
Sistema de Gerenciamento de Banco de Dados. O software que controla todo acesso ao banco. No curso: MariaDB, dentro do XAMPP.
SQL aulas 1 e 4
Structured Query Language. Linguagem padrão dos bancos relacionais.
Subconsulta aula 6
Um SELECT dentro de outro, usado com IN ou EXISTS.
Superchave aula 3
Qualquer conjunto de colunas que identifica cada linha de forma única; pode ter colunas sobrando.
Trigger (gatilho) aula 7
Código que o SGBD executa automaticamente antes ou depois de um INSERT, UPDATE ou DELETE.
Tupla aula 1
Nome formal da linha (registro) de uma tabela.
View (visão) aula 7
Consulta armazenada que se comporta como tabela virtual. Não guarda dados.
